# Changelog

All notable changes to Color Boxes are documented in this file.
The format follows [Keep a Changelog](https://keepachangelog.com/) and the

## [1.0.0] - 2026-10-10

### Added
- Initial release: a dark theme with solid color blocks: shadow purple, electric plum, cyan, amber and acid green.
- Support for Redmine 7+ (`themes/` directory).
- Header, login and favicon artwork.
